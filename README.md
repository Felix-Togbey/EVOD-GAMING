# EVOD Gaming

**Connect. Compete. Conquer.**

EVOD Gaming is a multi-page gaming community website designed for PC gaming enthusiasts. It provides a platform where gamers can explore popular games, discover gaming news, view upcoming events, and interact with a gaming community.

## Features

- **Home Page:** Introduction to EVOD Gaming, featured games, latest news, and upcoming events.
- **Games Page:** Browse games, search by name, filter by genre, sort alphabetically, and add games to favorites.
- **News Page:** Explore gaming news using category filters and search functionality.
- **Events Page:** Discover upcoming gaming tournaments and competitions.
- **Join Page:** Registration form with input validation and automatic event selection.
- **Contact Page:** Contact form with input validation.
- **Dark/Light Mode:** Switch between dark and light themes.
- **Responsive Design:** Adapted for desktop, tablet, and mobile screens.

## Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling, layouts, and responsive design.
- JavaScript – Interactivity and dynamic functionality.

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code or another code editor.
3. Open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code for a better development experience.

## Important Notes

This project is a frontend-only website. The registration and contact forms currently use JavaScript validation and simulated success messages. They do not create real accounts or send messages to a server.

## Project Objective

The objective of EVOD Gaming is to demonstrate practical skills in HTML, CSS, and JavaScript by developing an interactive, responsive, and user-friendly gaming community website.
